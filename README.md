# youtube-clone-html-css

A responsive YouTube clone built using only HTML and CSS.

## About the Project

This project was developed as a front-end study and training exercise focused on improving HTML and CSS skills through practical application.

The interface is inspired by an older version of YouTube, with the goal of recreating its visual structure while practicing layout organization, styling, responsiveness, and component positioning.

This was my first front-end project and it was developed in approximately one week.

## Purpose

The main purpose of this project is learning and portfolio development.

Several modifications and structural adjustments were made throughout the process as part of experimentation and practice with both technologies.

Future updates may be added to modernize the interface while still keeping the project focused exclusively on HTML and CSS.

## Project Structure

The folders were organized to keep the project structure simple and easy to understand.

Additional notes:

- Project folders such as `styles/`, `icons/`, `thumbnails/`, and `channel-pictures/` are separated and organized according to their respective purposes.

## Technologies Used

- HTML5
- CSS3
